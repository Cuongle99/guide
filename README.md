# Quy trình Cài đặt, Cấu hình và Đóng gói Theme PrestaShop (Dev)

Chào mừng bạn đến với tài liệu hướng dẫn tiêu chuẩn dành cho Developer khi làm việc với **PrestaShop (Bản Dev)** và bộ công cụ **Leo Elements**.

Tài liệu này được chia thành 4 phần chính theo đúng luồng công việc thực tế:

1. **[Phần 1: Cài đặt PrestaShop bản Dev](phan-1-cai-dat-prestashop-dev/README.md)** — Chuẩn bị mã nguồn, chạy trình cài đặt với thông số tiêu chuẩn và cấu hình thư mục quản trị.
2. **[Phần 2: Cài đặt Theme & Cấu hình cơ bản (Leo Elements)](phan-2-cai-dat-theme-leo-elements/README.md)** — Đổi tên theme, tối ưu hiệu suất môi trường Dev, dọn dẹp Hook và khởi tạo Profile.
3. **[Phần 3: Cấu hình Font chữ và Biến màu sắc (SCSS)](phan-3-cau-hinh-font-va-scss/README.md)** — Sử dụng trình biên dịch Compass, nhúng Google Fonts và đồng bộ bảng màu từ Figma.
4. **[Phần 4: Export và Đóng gói Quickstart & Theme](phan-4-export-va-dong-goi/README.md)** — Xuất Sample Data, chuẩn hóa Charset SQL, thêm `index.php` bảo mật và chạy Script đóng gói tự động.
