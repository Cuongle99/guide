# 3. Lấy code Theme

1. #### Tạo thư mục Theme (file base dùng fw cty làm theme)
2. Mở **cmd** tại thư mục theme đó , chạy lệnh **shopify theme pull -s store -t theme\_id** sẽ lấy được code của theme (or copy folder theme base vào).
3. Để chỉnh sửa theme, upload file code lên store đang làm, tại **cmd** chạy lệnh **shopify theme dev -s store -t theme\_id.**

_**Note**_**:**&#x20;

* **theme\_id**: Lấy từ mục **Customize** trong **Admin Store.**
* **store**: URL cửa hàng, ví dụ: **https://ap-leotheme.myshopify.com.**
