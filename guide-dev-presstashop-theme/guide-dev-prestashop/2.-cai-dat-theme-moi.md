# 2. Cài Đặt Theme mới

**I. Cài đặt môi trường**

1. download & install ruby [https://rubyinstaller.org/downloads/](https://rubyinstaller.org/downloads/)
2. go lenh tren cmd: **gem install shopify-cli**
3. kiểm tra xem install thành công hay k: **shopify version**

**II. Cài đặt theme**

1. Tạo cửa hàng và cài đặt theme **base** > **Publish**.
2.  Cài đặt các app cần có của 1 theme&#x20;

    [https://prnt.sc/M9HJgoakoSoi](https://prnt.sc/M9HJgoakoSoi)

    * Judge.me Reviews&#x20;
    * Search & Discovery&#x20;
    * Translate & Adapt&#x20;
3. Kiểm tra và cài **Currency** là **USD** ( **Settings** → **General** → **Store defaults** → **Currency display** )
4. Cài đặt **Payments** ( **Settings** → **Payments** → (for testing) **Bogus Gateway** )
5. Kiểm tra và cài đặt **Markets** ( **Settings** → **Markets** ( **Primary** : **USD** ) ) , Tạo **Group Currency** and **Active Group** ( Ex : Mỹ , Đức , Pháp , Nhật… )
6. Cài đặt **Custom data** ( theo theme base ) ( **Settings** → **Custom data** → **Products, Collections** )
7. Thêm ngôn ngữ cho chủ đề  ( **Settings** → **Languages** ) ( Ex : Mỹ , Đức , Pháp , Nhật… )
8. Tạo Products và các kiểu product
